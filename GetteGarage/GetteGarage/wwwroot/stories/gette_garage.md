
## Why Build From Scratch

My day job evolved from purely backend ML and data engineering to include frontend
work, so naturally I brought that home with me. I wanted a personal
site that felt like a space for myself, not a template screaming
"hire me." Think digital garden, or a MySpace page without Tom.

## Over-Engineered on Purpose

I built the site from the ground up and deployed it to Azure, then
spent way too much time on CSS animations. The centerpiece of the
whole effort: a command line interface for navigating the site. Does
a personal website need a CLI? No. Is it bad UX on mobile? Also yes.
Did I enjoy building it anyway? Immensely.

## Still In Progress

There is a fishing idle game and another I'm working on meant to live inside the site. The site itself is constantly evolving as I add more art and games. Definitely an ongoing excuse to keep tinkering. It also has a database of high scores connected to the fishing game that acts as a global leaderboard. Any new games I add can also connect to this API service.
