## A Laptop That Wouldn't Stay Awake

I got a new laptop, immediately wiped Windows for Linux, and ran into
one problem: the machine kept falling asleep while I played piano
through a MIDI input. Neither FLStudio nor Strawberry would keep it
awake during playback on Linux.

## Fifteen Hours to Avoid a Two-Second Fix

Rather than just changing the power settings, I spent fifteen hours
writing a bash script to handle it automatically. The result is on
GitHub as "smart-kde-inhibitor": a tiny, extremely specific tool
built entirely out of stubbornness. Zero stars so far.
